Cloud & Storage Setup Guide

1. Supabase Document Storage (Free 1GB, No Credit Card)

  1. Go to supabase.com and create a free project.
  2. In Supabase Dashboard → Storage → click New bucket.
  3. Name it study-materials and turn ON "Public bucket".
  4. Go to Project Settings → API, copy your Project URL and anon key.
  5. Paste them into js/supabase-config.js.

2. Firebase Database & Google Auth

  1. Open js/firebase-config.js and verify your firebaseConfig credentials.
  2. In Firebase Console → Authentication → Sign-in method, enable Google.
  3. In Firebase Console → Firestore Database → Rules, paste the rules from firestore.rules and click Publish.

Prism has full built-in Base64 fallback, so uploading and downloading documents works immediately even before entering Supabase keys!
